Guía para docentes

1. Ingresar al sistema

Como docente subes documentos en nombre de estudiantes de tu institución y revisas los reportes para apoyar tu evaluación.

  1. Ingresa con tu usuario o correo institucional y tu contraseña.
  2. Pulsa Iniciar sesión; llegarás a la bandeja de documentos.
{% include "manual/_figura.html" with shot=shots.login %}

2. Cómo subir un documento

  1. Entra a Documentos y pulsa Subir documento.
  2. Elige el Alumno a cuyo nombre se subirá el trabajo y completa los datos.
  3. Selecciona el archivo (PDF o DOCX) y pulsa Registrar.
  4. Inicia el análisis desde el menú de acciones del documento y espera a que el reporte esté listo.
{% include "manual/_figura.html" with shot=shots.bandeja %} {% include "manual/_figura.html" with shot=shots.subir %}
ConsejoEn Alumnos pendientes ves a los estudiantes que se registraron y esperan ser aprobados.

Cada fila de la bandeja tiene el botón Ver y un menú «…» con las acciones disponibles.

4. Cómo leer el reporte

{% include "manual/_leer_reporte.html" with key="docente" con_capturas=True %}
  1. Abre cada fuente para comparar los fragmentos coincidentes.
  2. Si una fuente no corresponde (por ejemplo, un texto citado correctamente), exclúyela del cálculo; el reporte se recalcula.
ImportanteTú decides qué coincidencias son aceptables; el sistema solo las señala.

5. Cómo generar y verificar el certificado

  1. Con riesgo bajo o medio, pulsa Generar certificado en la página del reporte (o en el menú «…» del documento).
  2. Descarga el PDF y entrégalo al estudiante.
  3. Para comprobarlo, abre el enlace de verificación o escanea el código QR.
